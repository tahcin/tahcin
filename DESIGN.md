# Continuous Form

This profile is a printout.

It is one long run of fanfold computer paper: tractor-feed margins, sprocket
holes, greenbar bands, perforated folds torn into sheets. A dot-matrix printer
strikes the facts, a person marks them up in ballpoint, and an office stamps
the verdicts. Every sheet is generated by code in `src/`, and a GitHub Action
reprints the whole job every morning.

## Why a printout

- **Parchi** is named after a chit, and its own interface is warm paper, carbon
  ink and rubber-stamp colour. The profile extends that world rather than
  inventing a new one.
- Dot-matrix printing is still how Indian railway tickets and bank passbooks
  are made. It is familiar, a little bureaucratic, and full of character.
- The luck research is about noticing small chance events. A printout is a
  record of exactly that kind of detail.
- GitHub's constraints fit the medium. A README is a vertical stack of images
  with gaps between them; here every gap is a torn perforation between sheets,
  and the sprocket holes are punched through, so GitHub's own background shows
  through them in light and dark themes alike.

## Three voices, three colours

| Voice | Who | Colour | Type |
|---|---|---|---|
| The machine | facts, data, job fields | ink `#18181B` | a hand-built 5x7 dot-matrix face (`src/lib/dotmatrix.py`), Martian Mono |
| The human | opinions, asides, the first person | ballpoint `#2A3FD0` | Instrument Serif Italic, pen strokes |
| The institution | verdicts and results | stamp red `#D8362A` | used sparingly: Parchi's verdict, LIVE jobs, FIRST PLACE |

Headlines are Archivo at its narrowest, heaviest instance, pressed onto the
sheet. Paper is `#F2EDE1`; the time card is buff `#E7D6A4`; Parchi's chit is
pale yellow, written in carbon violet `#4A3B9A`.

## Motion

Five verbs, defined once in `src/lib/motion.py`:

- **STRIKE**: the printhead hits paper; a column of pins appears in one frame.
- **FEED**: paper advances in steps, never eased (the Deadline Dash log).
- **PEN**: a person draws a stroke with a soft ease.
- **SLAM**: a rubber stamp lands with an overshoot.
- **PRESS**: heavy type lands in one short blow.

Entrances play once. Only machines loop: the blinking cursor, the hourly log,
the falling chance events, Parchi's stamp re-inking itself in eleven
languages. Every element's resting state is its final state, so with
`prefers-reduced-motion` the profile shows the finished composition and
nothing moves.

## How it is built

```
src/
  build.py            prints every sheet into ../assets
  fetch.py            refreshes data/ from the GitHub API (needs GITHUB_TOKEN)
  lib/paper.py        the fanfold sheet: torn edges, sprocket holes, greenbar, grain
  lib/dotmatrix.py    the 5x7 pin face
  lib/fonts.py        HarfBuzz shaping, glyphs drawn as vector outlines
  lib/motion.py       the motion verbs as CSS
  lib/printing.py     struck lines, rules, sheet headers, shared filters
  sheets/*.py         one module per sheet
  data/               contribution calendar, Deadline Dash commits, Parchi's languages
  fonts/              OFL fonts (licences in fonts/licenses)
  tools/snap.py       renders an SVG as an <img> and captures frames at set times
  tools/preview.py    renders README.md through GitHub's Markdown API into a profile-page mock
```

```sh
pip install -r src/requirements.txt
python src/build.py               # all sheets
python src/build.py parchi hero   # just some
GITHUB_TOKEN=... python src/fetch.py
pip install playwright && playwright install chromium   # for the tools
python src/tools/snap.py assets/hero.svg --times 1,3,7 --theme light
GH_TOKEN=... python src/tools/preview.py --shots
```

`.github/workflows/print.yml` runs fetch and build at 06:17 UTC every day, and
whenever `src/` changes, then commits the new printout.

## GitHub constraints, and what was done about them

- **No JavaScript, no CSS in the README.** All motion lives inside the SVGs as
  CSS keyframes, which GitHub renders when an SVG is used as an image.
- **No web fonts in Firefox.** GitHub serves repository files with
  `Content-Security-Policy: default-src 'none'`. Chrome still allows embedded
  data-URI fonts under that policy; Firefox does not. So no sheet contains a
  `<text>` element: every line is shaped with HarfBuzz (including Indic
  conjuncts) and drawn as outlines.
- **No scroll triggers.** An SVG used as an image starts its animations when
  the page loads, not when it scrolls into view (tested in Chrome and
  Firefox), and GitHub strips the JavaScript and `loading` attributes that
  could change that. So the hero carries the one-shot print, and most sheets
  below it keep one quiet, purposeful loop so something is alive when you
  arrive: falling chance, the re-inking verdict stamp, a red pin on the sync
  bot's newest week, a ring around today on the time card, a cursor at the end.
- **Images are not interactive.** Links live on the image wrappers and in the
  small captions between sheets. Nothing inside an SVG is clickable.
- **Theme.** The paper is an object, not a background, so it reads on light,
  dark and dimmed themes without `<picture>` switching. The holes show
  whichever theme is active.
- **Size.** Sheets are 80 to 330 KB raw and 16 to 90 KB gzipped, which is how
  raw.githubusercontent.com serves them. Dot-matrix glyphs are defined once and
  placed with `<use>`; large type is rounded to whole units.
- **Narrow screens.** Each sheet scales to fit. On a phone the headlines, the
  name and the big numbers stay legible; the smallest print becomes texture.
- **Scheduled workflows** in public repos are paused by GitHub after 60 days
  without repository activity. If the printout ever stops refreshing, run the
  workflow by hand from the Actions tab.
